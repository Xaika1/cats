# Котокафе — десктоп-клиент

Electron-приложение для учёта котиков и их здоровья. Интерфейс собран на Bootstrap 5 в «кошачьей» палитре, страницы рендерятся из шаблонов Nunjucks, данные приходят с Django API.

## Запуск

Сначала запустите сервер (см. `all/Django_template_web_api_basic/README.md`), затем:

```bash
npm install
npm start
```

`npm start` собирает шаблоны и интерфейс в `dist/` и открывает окно приложения.

Адрес API по умолчанию — `http://127.0.0.1:8000/api`. Другой адрес:

```bash
CATS_API_URL=http://192.168.1.10:8000/api npm start
```

Windows (cmd):

```bat
set CATS_API_URL=http://192.168.1.10:8000/api
npm start
```

На Linux с Wayland при проблемах с окном: `npx electron . --ozone-platform=x11`.

## Команды

| Команда | Действие |
|---|---|
| `npm start` | сборка и запуск приложения |
| `npm run build` | сборка в `dist/` |
| `npm run dev` | интерфейс в браузере на `http://127.0.0.1:4173` |
| `npm test` | проверка рендера всех шаблонов |
| `npm run dist` | сборка .exe для Windows в папку `release/` |

## Сборка .exe для Windows

Выполняется на компьютере с Windows.

1. Установите [Node.js](https://nodejs.org/) версии 20 или новее (LTS).
2. Откройте «Командную строку» в папке клиента:

   ```bat
   cd путь\к\all\electron_1.1.0\electron
   ```

3. Установите зависимости и соберите:

   ```bat
   npm install
   npm run dist
   ```

4. Готовые файлы появятся в папке `release`:
   - `Kotokafe-1.0.0-win-x64.exe` — установщик (создаёт ярлык на рабочем столе и в меню «Пуск»);
   - `Kotokafe-1.0.0-portable.exe` — переносная версия, запускается без установки.

Приложению нужен запущенный сервер (см. README сервера). По умолчанию оно подключается к `http://127.0.0.1:8000/api`; если сервер на другом компьютере, перед запуском .exe задайте адрес:

```bat
set CATS_API_URL=http://192.168.1.10:8000/api
"Котокафе.exe"
```

Если Windows SmartScreen предупреждает о неизвестном издателе, нажмите «Подробнее» → «Выполнить в любом случае»: приложение не подписано сертификатом.

## Экраны

- **Вход и регистрация** — проверка полей, индикатор надёжности пароля, сообщения сервера.
- **Котики** — карточки с фото и состоянием, счётчики по состоянию (работают как фильтр), поиск, фильтры по полу и породе, сортировка, форма добавления с загрузкой фото перетаскиванием.
- **Карточка котика** — фото, порода, пол, возраст, вес, график веса, журнал здоровья с фильтрами по состоянию и датам, добавление, изменение и удаление записей, редактирование и удаление котика.
- **Профиль** — данные сотрудника и их редактирование, выход.

Тема переключается кнопкой в шапке и запоминается.

## Устройство

```text
electron/main.js      окно приложения, хранение токенов (safeStorage)
electron/preload.js   мост между окном и основным процессом
templates/            шаблоны страниц Nunjucks
build/precompile.js   сборка шаблонов в www/templates.js
www/app.js            запуск, уведомления, окно подтверждения
www/conf/             адрес API, запросы, состояние, маршрутизация, рендер
www/views/            вход и профиль, котики и здоровье
www/static/custom/    стили темы и переключатель темы
```
